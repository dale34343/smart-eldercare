# 多模态AI驱动的智慧养老数字服务平台

界面简称：智慧养老。版本：2026.09.28.2。

固定体验入口：https://dale34343.github.io/smart-eldercare/

本轮为零预算项目交互演示，不是生产系统、正式微信小程序或收费 SaaS。无需登录或注册，电脑关机不影响静态站点由 GitHub Pages 托管。

用于项目展示和原型体验的静态网页，包含财富守护、康养照护和精神陪伴三个模块，以及老人、家属和运营体验视图。

## 使用边界

- 服务机构、价格、活动、人员及健康记录均为示例。
- 预约、记录和身份切换仅用于本浏览器演示，不会联系真实机构，不会扣费。
- 数据只保存在当前浏览器，不提供跨设备同步或真实用户身份认证。
- 未接入支付、真实医疗服务、设备监测、紧急救援或大模型服务。
- 请勿输入真实身份证号、健康档案、财务信息等敏感资料。

## 发布内容

本目录仅包含公开演示所需的 HTML、CSS、JavaScript 和 Lucide 图标库。无需安装依赖或运行后端。

PPT 原件、研究资料、本地数据库、账号凭证和个人照片不属于发布内容。

第三方图标库的许可说明保留于 `vendor/LUCIDE-LICENSE.txt`。

## 体验流程

1. 老人打开“需求助手”，选择“帮我约周三的陪同复诊”，核对具体北京时间，补全虚构时间与地址，保存草稿并本人确认。
2. 家属只能在有效授权内查看与协助。代预约、改约均须本人确认；默认不共享健康读数、收支和聊天。
3. 切换运营视图处理同一订单：接单、开始服务、提交完成记录。
4. 老人确认服务完成，运营回访归档。实际费用由本人另行确认，报价不自动入账。

同一浏览器切换虚构角色；不同设备、不同浏览器不共享记录。浏览器前端过滤只展示业务规则，不提供真实身份认证或服务端安全保证。

## 数据与恢复

使用虚构数据；记录保存在当前浏览器，不跨设备同步；不产生真实订单或扣费，请勿输入真实敏感信息。

保留旧存储键 eldercare-public-demo-v1，数据结构升级为 version 2。旧记录迁移保留原订单及账本；旧授权暂保留30天并提示本人复核，不补造本人确认历史。数据损坏不静默删除，可选择临时体验或明确确认重置。本项目不调用 localStorage.clear()。

正常存储下刷新、关闭页面重开可继续；浏览器清理或无痕会话结束可能丢失。存储不可用采用明确提示的内存降级；写入失败显示“未保存”。支持同浏览器多标签修订版本冲突检查；支持 Web Locks 的浏览器还会串行写入。不支持 Web Locks 的旧内核不承诺跨标签强原子事务。

## 能力边界与外部依赖

- 需求助手是本地规则，不是真实大模型。未接入录音、识别、朗读、设备、真实支付、派单、拨号和后台推送。
